# 콘텐츠 시장조사

여러 브랜드의 콘텐츠를 조사하고 근거에 따라 기획하는 온라인 웹서비스.

현재는 설계 및 기본 구조 준비 단계입니다. 실행 가능한 웹 앱, 배포, 실제 API 연결은 아직 없습니다.

- 코드: GitHub
- 저장 및 Google 로그인: Supabase
- 영상·조회수·댓글: YouTube API
- 분석·기획: Gemini 무료 API 우선, 제공자 교체 가능
- ChatGPT Plus: 개발 지원과 결과 검토
- 호스팅·예약 실행: 검증 후 결정

[설계 및 구현 계획](docs/design.md)

API 키, 비밀번호, 실제 조사 자료는 공개 저장소에 넣지 않습니다. 키는 서버 비밀 설정으로 관리합니다.
