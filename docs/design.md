# 설계 및 구현 계획 v1

## 상태
요구사항 정리 및 파일 구조 준비 단계. 2026-11-06 GitHub 파일 작성 권한을 실제 업로드로 확인했다. 실제 API 수집·분석·배포·데이터베이스 변경은 수행하지 않았다.

## 사용자와 브랜드
- 온라인 웹서비스, Google 로그인, 초기 허용 사용자 1명, 이후 팀원 확장.
- 마케팅·사업·콘텐츠·AI 분야. 브랜드별 복수 플랫폼 연결.
- 브랜드 등록·수정·보관·선택 설정 복사. 브랜드 수 제한을 3개로 고정하지 않음.
- 필수: 이름·플랫폼·분야·시청자. 목적·계정 주소·말투·제외 주제는 선택.
- 보관 시 정기 조사 중지. 이전 자료 출처 유지.

## 조사 흐름
브랜드 → 키워드 또는 계정/콘텐츠 주소 → 추천 근거 확인 및 후보 선택 → 수집·기본 분석 → 종합 결과 → 선택 콘텐츠 심층 분석 → 주제 선택 → 기획 → 편집 및 제작 관리.

초기에는 소수 계정으로 시작해 100개 이상으로 확대. 기본 기준과 조사별 변경을 지원. 언어·지역도 선택하며 해외 결과는 한국어와 원문 링크 제공.

## 수집 및 성과
- 첫 플랫폼 YouTube, 긴 영상과 Shorts 각각 비교. 이후 Instagram·Threads.
- 최근 3개월 같은 채널·같은 형식의 전체 적격 영상으로 산술평균 계산. 평가 영상도 포함.
- 긴 영상 게시 후 7일 미만, Shorts 3일 미만 제외.
- 고성과는 평균 3배 이상, 저성과는 0.5배 이하.
- 고성과 조회수 상위 10개, 저성과 하위 10개 기본. 기간·개수 변경 가능.
- 부족하면 실제 개수만 표시. 10개 미만이어도 표본 부족 경고와 참고용 판정.
- 평균 0 또는 결측은 판정 보류. 전체 평균을 상하위 20개만으로 계산하지 않음.
- 조회수순·상대 성과 제공. 경과시간 보정 점수는 미확정.
- 여러 계정의 유사 주제를 같은 형식끼리 비교. 채널 규모와 게시 시점 표시.
- 서로 다른 채널 3곳 이상 고성과 확인 시 유망 주제, 1~2곳이면 관찰 중. 같은 채널은 1곳으로 계산.
- 단어뿐 아니라 시청자 상황·문제·원하는 결과를 분류.

## 분석과 근거
기본: 제목·설명·공개 수치·일부 인기댓글. 선택적 심층: 확보 가능한 자막·대본과 확대 댓글, 도입부·전개·주장·보완점.

댓글은 내용 만족·불만·추가 질문의 근거. 인기 순위와 반복 빈도 구분, 실제 표본 내 분모와 빈도 표시. 자막 자동 확보 우선, 실패 사유 표시 및 직접 보완. 타 채널 자막 자동 확보는 미검증. 음성 인식은 후속 검토.

첫 버전은 텍스트 분석. 썸네일은 표시만 함. 광고·협찬·이벤트·유명인 출연도 포함하되 확인 근거 표시와 제외 필터 제공.

관측 사실/계산/가설/제안/확인 불가 구분. 모든 분석에 원본 링크·수집 시점·대상 수·비교 조건 연결. 반대 사례 포함. 본문 미확보 시 본문 추론 금지. 근거 없는 점수·확률 금지.

수정은 해당 결과 또는 이후 브랜드 기준에 적용, 원본과 수정 이력 보존. 모델 자체 학습으로 표현하지 않음.

## 결과와 기획
- 첫 화면 브랜드 현황, 결과 첫 화면은 종합 요약.
- 메뉴: 전체 현황 / 브랜드 / 시장조사 / 조사 자료 / 기획·제작 / 설정.
- 통합 목록과 실행별 보고서 제공. 표·카드 전환 시 필터·정렬·선택 유지.
- 선택한 주제만 기획. 개요 또는 초안까지 선택. 근거 연결.
- 직접 편집 및 선택 부분 AI 수정, 이전 버전 복원.
- 상태: 아이디어 → 기획 완료 → 제작 중 → 발행 완료.
- 발행 후 실제 성과 연결은 후속 범위.

## 정기 실행과 비용
매주 조사 및 수동 실행. 기준 충족 신규 계정 자동 추가, 제외 계정 재추가 방지. 계정·콘텐츠·비용 한도 내 우선순위 처리, 제외·실패 표시. 웹 내부 알림만 제공.

AI 기본값과 실행별 변경, 사용 모델·자료·지침·시점 기록. 무료 한도 소진 시 저장 후 대기, 자동 유료 전환 금지. Gemini 무료 API 우선, ChatGPT Plus는 개발·검토에 활용. 다른 모델로 재분석 시 새 버전.

## 구현 순서와 미확정 사항
1. 서버 비밀 설정으로 API 연결 후 영상 목록·조회수·댓글 수집 시험.
2. 형식 판별과 자막 확보율 검증. 라이브 처리 결정.
3. 기간 경계·배수 경계·0 평균·표본 부족·결측 계산 검증.
4. 브랜드/계정/영상/수치 스냅샷/조사/분석/근거/기획/버전 저장 구조 및 사용자 접근 정책.
5. 기본 화면과 조사 상태 구현.
6. Gemini 소량 시험과 근거 ID·수치 대조, 품질·사용량 기록.
7. 예약·재시도·중복 실행 방지·한도 정지·부분 결과 검증.
8. 무료 운영 가능성 확인 후 호스팅 확정 및 로그인·배포 검증.

추천 가중치, 댓글 표본 수, 시간대와 3개월 경계, 경과시간 보정, 성장 이력, 자료 보존·갱신·삭제 조건, 팀 권한 범위는 추가 확인한다.
